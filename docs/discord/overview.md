**Polymarket 足球盘口 · 网状盘口图 dApp**

一个纯前端的 Polymarket 足球下注应用：把一场比赛的全部盘口画成一张关系图（网状盘口图），直接点图上的节点下单。没有服务器、没有数据库——图在浏览器里现算。
第一次用？点顶栏「说明」看 6 步上手流程。

**📂 选比赛**
左栏列出今明两天的足球赛（中文队名 + 英文副行、联赛 · 开球时间 · 成交量、状态徽标）。
• 队名或联赛名搜索，中英文都认
• 筛选标签多选：Live / Upcoming / Ended 取并集，「我的」与它们取交集，「全部」清空
• 行上的「持仓」徽标 = 你在这场比赛里持有仓位（赛事级判断，含图上没画的盘口）

**🕸 看盘口图**
固定槽位模板，每场比赛同一副骨架，槽位位置固定，数据只填充不重排。默认收起外围两档、画 33 个节点；点右上角「展示更多」展开到 47 个（全场大小球到 8.5、单队进球到 5.5、让球到 ±5.5）。
• 中心三节点 = 反推的进球数（总 / 主 / 客），无独立盘口
• 盘口节点各显示一侧及价格：大小球取「大」、胜平负取「Yes」、让球取该队一侧
• 颜色 = 主队(暖) / 客队(冷) / 中性；实心 = 有实时双边报价，暗色虚线 = 只有 Gamma 快照价
• ✓ 已打出 = 该进球线已达成；白描边 = 当前选中；虚线空槽 = 该场没这条线
• 右上角切价格口径：概率 % ↔ 欧赔（十进制赔率 = 1 / 价格，买价 0.55 → 赔率 1.82）；旁边的「展示更多 / 折叠盘口」展开外围盘口，展开或收起都会重置缩放和选中

**🏷 持仓标记**
持仓时节点右上角有徽标：字母表示未结/已结，颜色表示哪一侧。
• 绿 · 持 = 持有本侧、未结算
• 灰 · 结 = 持有本侧、已结算
• 红 · 持/结 = 持有本盘的另一侧（如买了「小」但槽位显示「大」），借用到该槽上
悬停看具体持仓、数量、均价/现价、盈亏。
⚠️ 模板画不出的盘口（互射、正确比分、半场，以及超出模板范围的总球 9.5+、单队进球 6.5+、让球 ±6.5）没法在图上标记，但仍走赛事级「持仓」徽标显示——这是预期，不是 bug。

**👛 手机 / 桌面钱包**
• 桌面扩展、钱包内置浏览器：检测已安装的钱包后直接连接，多个钱包可选择
• 手机普通浏览器 / 主屏 PWA：点「连接手机钱包」，通过 WalletConnect 唤起 MetaMask、币安等兼容钱包，授权确认仍在钱包 App 内完成
• 安卓连接和签名按所选钱包的应用信息定向唤起；钱包缺少有效应用信息时保留原跳转。Chrome 对 MetaMask 等浏览器类钱包仍可能显示应用选择确认，本站不保证免弹框
• 安卓 PWA 会向钱包提供返回本站的地址；是否自动回跳、是否回到原 PWA 窗口仍由钱包与系统决定，不保证自动返回

**🛒 下单**
点绑定盘口的节点开下单面板（中心反推节点和空槽不可下单，只高亮）。需要连 Polygon 钱包；持仓与余额读的是代理钱包，不是签名地址。下单签名由所连接的钱包完成（Deposit Wallet / ERC-7739 外壳），授权由 Polymarket relayer 代发、不花 gas。
顶栏最右那个按钮显示的是**可交易余额**（代理钱包里的 pUSD）——下单能动用的就是这笔钱；点开是完整读数：签名地址 / 资金地址 / POL(gas) / 存款入口 / 交易授权 / 断开。还没存款时它显示签名地址上的金额并标「未存入」。

**📋 我的订单**
顶栏「订单」查看持仓、成交和完结记录。点击记录跳转到对应盘口，并打开对应方向的下单面板（含 Under / No）；比赛不在列表中或盘口无法定位时显示「盘口不存在」。持仓左侧勾选框仅用于选择导出图片，不触发跳转。

**⚙️ 数据链路**
• 赛事/盘口：Gamma（CORS 全开，浏览器直连）；足球用 `tag_slug=soccer`
• 列表不带盘口（一页 4MB→470KB），选中比赛才按需拉那一场（约 500KB），react-query 缓存 5 分钟
• 实时价格走 CLOB WebSocket
• 手续费两项分开预估显示：本平台 builder 费从 `fetchBuilderFeeRates` 读（拿不到退回 5bps）、Polymarket 盘口费从盘口元数据读（拿不到按体育盘口默认预估）；都按吃单口径估算、仅显示用、不挡下单

**🚀 开发 / 部署**
`npm run dev` 本地开发 · `npm run build` 构建 · `npm run test` 测试 · `npm run deploy` 发到 Cloudflare Workers。
正式地址：https://polysoccer.zhangsanfengzhsh.workers.dev
可「添加到主屏」当手机 app 用（PWA）：独立图标、全屏启动、离线兜住界面壳；更新随部署自动生效，无需重装。
签名后端在独立仓库 `polymarket-builder-sign`（Cloudflare Workers），持有 builder 凭据，本前端包里不含任何机密。
