## 2026-09-29 · 顶栏显示余额、价格口径开关进画布

价格口径开关（概率 % ↔ 欧赔）从顶栏挪到画布右上角——它在换节点上那些数字的读法，摆在数字旁边才看得出切完在看哪里的数。

## 2026-09-30 · 手续费拆成两项显示
下单面板的手续费从一行拆成两行：**Polymarket 盘口手续费（预估）** 和 **本平台手续费**，各自单列、金额分开算。此前只显示本平台一项，用户看不到 Polymarket 侧要收多少。
· Polymarket 费率按盘口元数据实时读取（免鉴权，与下单同一份数据），零费率盘口如实显示 0；读不到时按体育盘口默认值预估，不阻止下单。
· 按吃单口径预估：`份额 × 费率 × [价格 ×(1−价格)]^指数`。限价单会额外提示「若作为挂单成交则不收此项」。
· 合计 / 到账那行的文案统一改成「预估」措辞——手续费是按当前价预估的，不再写成「实际扣款」，以实际成交回执为准。

## 2026-09-30 · 可添加到手机主屏（PWA）
现在能把应用装到手机主屏当 app 用：安卓 Chrome 会提示「安装」，iOS Safari 走「分享 → 添加到主屏幕」。装完是独立图标、全屏启动，没有浏览器地址栏。
· 只用 Service Worker 缓存「壳」（界面代码）；盘口价格、战绩这些仍每次联网拉，绝不显示旧数据。
· 更新照旧：一次 `npm run deploy`，网页版和已装到主屏的版本一起更新，不用重装。
· 需用 https 打开（正式域名或 Tailscale 地址都满足）。这一步只是把网页装成 app，不改变钱包连接方式（手机连钱包仍需后续接 WalletConnect）。
