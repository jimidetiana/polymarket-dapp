## 2026-09-28 · 反向持仓标记改红
「持有本盘另一侧」的角标从琥珀橙改成红色：一是和本侧的绿形成对应，二是避开主队的暖橙配色，不再混色。

## 2026-09-29 · 顶栏显示余额、价格口径开关进画布
顶栏右上角那个按钮不再显示钱包地址缩写，改显示**可交易余额**（代理钱包里的 pUSD）：地址缩写看不出是哪个钱包、有多少钱，而「我的钱呢」正是点开它的理由。完整读数（签名地址、资金地址、gas、存款入口、交易授权、断开）仍在点开后的浮窗里。还没存款时按钮显示签名地址上的金额并标「未存入」。
价格口径开关（概率 % ↔ 欧赔）从顶栏挪到画布右上角——它在换节点上那些数字的读法，摆在数字旁边才看得出切完在看哪里的数。

## 2026-09-29 · 补 73 条国家队译名
国际比赛周的国家队（Nations League、世预赛）此前全显示英文：词典是从俱乐部资料库批量来的，国家名一个都没有。这次补了 73 个国家和地区名，当前窗口内的比赛不再出现英文队名。以后缺译名的补法固定下来了：`node scripts/dict/missing-teams.mjs` 扫出缺的 → 译好 → `--merge` 合并进词典。

## 2026-09-29 · 战绩播报
新增 `npm run stats`：从 Polymarket 的成交活动重建每场盘口的输赢与盈亏，算胜率后发到战绩频道。口径按开赛时刻分「赛前套利」和「真押注」——赛前就平掉的不计入胜率。

## 2026-09-29 · 首页操作说明
顶栏新增「说明」按钮，打开一个 6 步操作说明弹窗：连接钱包 → 存款 → 交易授权 → 选比赛 → 点节点下单 → 查订单。第一次访问会自动弹一次，之后只从按钮打开。弹窗底部附 Discord 邀请链接。
